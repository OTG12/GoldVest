# Aurelis Private Wealth — landing page

A React + Vite + Tailwind landing page template for a gold bullion custody
and advisory brand. Fictional placeholder brand — replace copy, licence
information, vault/insurer names, and contact details with your own before
publishing.

## Run locally

```
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```
npm run build
```

Output goes to `dist/`.

## What's inside

- `src/data/content.js` — all copy lives here; edit this file to change text
  without touching component markup.
- `src/components/` — one component per section (Navbar, Hero, Services,
  Process, Pricing, Security, Responsibilities, RiskDisclosure, FAQ, CTA,
  Footer).
- Tailwind tokens (colors, fonts) are defined in `tailwind.config.js`.

## Things you still need to fill in

Search the codebase for `[Insert ...]` placeholders — these mark spots where
real regulatory, custodial, or insurance information needs to go before this
site represents an actual offering. None of that information was supplied,
so none was invented.
